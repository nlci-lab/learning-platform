# Logos course: rules

These rules add to the root `CLAUDE.md`.

- **Subject:** using Logos Bible Software (Faithlife) for exegesis and translation work, for Bible translators and consultants.
- **Target (decided 2026-11-23):** the current Logos desktop app with the SIL Translator's Workplace (TW) library. Where a step depends on a paid feature set or on TW, say so.
- **Sources:** Faithlife's public help pages are the grounding documents. Cite the page for each how-to fact. Anything a help page does not confirm is marked unverified, to be checked in the app.
- **Levels:** Level 1 · First steps, Level 2 · Everyday use, Level 3 · Deeper study, Level 4 · Expert tools (set in `course.config.ts`). The names describe the material, not the reader.
- **First content:** guides for the Beginner topics (setup, navigation, library, search, guides and tools). The module list is decided with the user, from topics they give.
- **Still to decide:** the content types beyond guides and modules (for example keyboard shortcut lists).
- **Faithlife's material:** before publishing anything, confirm Faithlife's guidelines on screenshots and use of the Logos name. Until then, keep screenshots and their captions in drafts only. Never present the course as made or endorsed by Faithlife.
- **Version-specific facts:** Logos features change between versions. Each how-to fact names the version it was checked in and its source (Faithlife help pages, or a check in the app).
- **Micro modules** follow the platform's data format (root ADR 0002) and the four difficulty levels used across the courses.
