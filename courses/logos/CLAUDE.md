# Logos course: rules

These rules add to the root `CLAUDE.md`.

- **Subject:** using Logos Bible Software (Faithlife) for exegesis and translation work, for Bible translators and consultants.
- **To decide in Phase 2:** the audience level, the Logos version the course targets, and the content types (for example features and tools, workflows, keyboard shortcuts).
- **Faithlife's material:** before publishing anything, confirm Faithlife's guidelines on screenshots and use of the Logos name. Until then, keep screenshots and their captions in drafts only. Never present the course as made or endorsed by Faithlife.
- **Version-specific facts:** Logos features change between versions. Each how-to fact names the version it was checked in and its source (Faithlife help pages, or a check in the app).
- **Micro modules** follow the platform's data format (root ADR 0002) and the four difficulty levels used across the courses.
