*Written from Faithlife's help pages for Logos version 55 (November 2026). Points marked "checked in the app" were tried in Logos 55 on 24 Nov 2026.*

## What it does

**Text Comparison** shows one passage in several Bible versions. It compares each version with a **base text** and marks where they differ. It is available to all Logos users, on the desktop, on the web and on mobile. This guide describes the desktop app.

If you know Paratext, it is like a Text Collection. Logos also marks the differences for you.

## Open it

- **Tools menu:** **Tools** › **Text Comparison**.
- **In a Bible:** on the **Tools** tab of the toolbar, click **Compare**.
- **Right-click** a verse: choose **Selection** or **Reference** on the left, then **Text Comparison** on the right.
- **Selection Menu:** select a verse and click the Text Comparison icon.

To compare a longer passage, type a range in the reference box and press Enter.

## Choose the versions

1. Click the blue version link to the right of the reference box.
2. Tick the versions you want. You can type a name in **Find**, or choose a collection such as **Top Bibles**.
3. Click **Save** to keep this set. If you only click outside the list, Logos uses your choice now but does not keep it.

**Change the order** by dragging a version up or down in the list (checked in the app).

## The base text

Logos compares every version with one **base text**.

- When you open the tool, the base text is the Bible you used most recently.
- To change it, drag the version you want to the **top** of the list (checked in the app). Faithlife's help page gives another way: open the Bible you want, then open Text Comparison again.

## See the differences

The two buttons are **Show differences** and **Show base text**:

- **Show differences:** words that differ from the base text turn blue. Point at a small red circle to see the base wording. Each verse ends with how much it differs, as a percentage.
- **Show base text:** shows the base wording inside each version. Base words that a version leaves out appear in grey, struck through. Turn on **Show differences** first.

Small differences in capital letters, accents or punctuation can hide the real ones. In the **More Actions** menu (three dots), choose **Ignore case**, **Ignore marks** or **Ignore punctuation**. Faithlife's example: Romans 1:24 in Nestle-Aland 27 and the 1894 Textus Receptus looks completely different at first. With **Ignore marks** on, the difference drops to 14%.

## Verses or Interlinear

The **Verses / Interlinear** list changes the view:

- **Verses:** each version's text, verse by verse.
- **Interlinear:** each version's words lined up with the closest word in the base text. Small numbers show each version's own word order. This view needs the internet.

## Other options

All in the **More Actions** menu:

- **Follow** moves the tool with the Bible you are reading. Or choose a link set letter (see [Link sets](~/guides/link-sets/)).
- **Vertical** or **horizontal** layout.
- **Print/Export**, in Verses view, for the range in the reference box.

Text Comparison works offline for the text of your Bibles. Only the Interlinear view needs the internet.

## A quick look: F7

Press **F7** for a quick comparison of the verse you are in, or the text you selected. A small window shows the verse in a set of Bibles and marks the differences. It is not the same as the Text Comparison tool (both checked in the app). Faithlife's help pages say nothing more about it.

## Related tools

- **Multiple Books View** (also called Multiple Resources View): opens whole books side by side in one panel (**View** tab › **Add parallel text**). Faithlife's help page does not say that it marks differences.
- **Passage Analysis** (**Tools** › **Passage** › **Passage Analysis**) has three views that compare versions:
  - **Compare Pericopes:** how each version divides the passage into sections (pericopes).
  - **Cluster Graph:** which versions are close to each other.
  - **Version River:** verse by verse, how far each version is from a base version.

## For translators and consultants

These are suggestions for using the tool, not instructions from Faithlife.

- **Find the questions in a verse.** Where versions disagree, there is usually something to decide: a word with more than one sense, unclear grammar, or a difference in the manuscripts. Check those places in the commentaries and helps.
- **Order the versions on purpose.** The Paratext manual suggests ordering a text collection from more literal to less literal. In Logos you can do the same by dragging. Put a literal version at the top as the base text.
- **See differences in the Greek or Hebrew text.** Compare editions of the original text, turn on **Ignore marks** and **Ignore case**, and what is left is the real textual difference.
- **Check section breaks.** **Compare Pericopes** shows where published versions start new sections. That helps when you check a draft's paragraphs.
- **Compare with your team's draft or back translation.** Faithlife's help pages do not say that you can add your own draft to Text Comparison. Keep the draft or back translation open in Paratext beside Logos. Some consultants already compare back translations line by line in a Paratext text collection, because the differences are easy to see there (Funnell 2026).
