*Written from Faithlife's help pages for Logos version 55 (November 2026). Not yet checked in the app.*

## Find help

- **Help Center:** click the Help Center icon on the main toolbar, or press F1 (Windows). Search it, or choose a subject.
- **Help on one tool:** in a book or tool, choose **Help about this feature**. In a book it is on the **Home** tab; in a tool it is in the **More Actions** menu (three dots).
- **Online:** the toolbar's More Actions menu has **Online support center**, which opens Faithlife's help website (support.logos.com) in your browser.

## The Command Box

The **Command Box** is the text box at the top of the main toolbar. Type what you want and choose from the list. It is often faster than the menus. Alt+C (Windows) or Opt+Cmd+L (Mac) puts the cursor there.

- Type a **reference**, for example `John 3:16`, to open it in your Bible, open a study layout on it or search it.
- Type a **command**. Some useful ones:
  - `set preferred bible to` and a version name
  - `update now`, to install updates yourself
  - `sync now`, to sync your notes and highlights

## Toolbar shortcuts

The space on the main toolbar between the **Tools** icon and the **Help Center** icon holds your shortcuts. One click opens a book, a layout or a tool.

- **Add:** drag an open book or tool, a layout from the Layouts menu, or an item from the Library, Guides or Tools menu into that space.
- **Change:** right-click the shortcut to change its label or icon, or to put it in a folder.
- **Remove:** right-click the shortcut and choose **Delete**.

If you cannot see your shortcuts, make the Logos window larger, or click **More Shortcuts**.

## Keys worth learning first (Windows)

| Keys | Does |
|---|---|
| Alt+C | Go to the Command Box |
| Alt+S | Search |
| Alt+G | Guides menu |
| Alt+L | Library |
| Ctrl+G | Go to the reference box |
| Ctrl+K | Highlight the selected words |
| F1 | Help Center |
| F7 | Compare the verse in other Bibles |
| F11 | Full screen |

The Keyboard Shortcuts help page lists more, and the keys for Mac.
