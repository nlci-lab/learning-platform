*Written from Faithlife's help pages for Logos version 55 (November 2026). Not yet checked in the app.*

## Why this matters

Logos downloads books, updates and search indexes in the background. On a slow, shared or paid connection this can use a lot of data. You can choose when Logos downloads, and you can turn its internet use off.

## Open Program Settings

1. On the main toolbar, click the **More Actions** menu (three dots).
2. Choose **Program Settings**.

Changes take effect at once. There is no Save button.

## Limit downloads

In Program Settings, find the **Internet** section.

- **Automatically Start Downloads**: set it to **No** to stop downloads starting by themselves.
- **Download Between**: set a start and end time, for example at night when the connection is free.
- **Download New Books**: set it to **No**. New books still appear in your Library, but you download each one yourself.

When automatic downloads are off, you install updates yourself: type `update now` in the **Command Box** at the top of the window.

## Turn internet use off, and back on

Program Settings has a setting called **Use Internet**. Set it to **No** to work offline and **Yes** to go back online.

The help pages do not describe this setting in detail. Check its exact place in your own Program Settings.

## What changes offline

Some features stop working without the internet. Among them are the Bookstore, Atlas, the Media tool, Reading Lists and Sync. Others still work, but with less:

- **All Search** runs a simpler search.
- **Books Search** cannot find books that are only in the cloud.
- **Text Comparison** has no interlinear view.

If you turned internet use **off** in Program Settings, these features are greyed out or say they need the internet. If your computer is only **disconnected**, they look normal but give an error when you use them.

## Two things to remember

- Notes and highlights only sync between your devices when Logos is online.
- Logos must go online from time to time to renew your licence. For a monthly subscription, that is at least once a month.
